# OCHA Utilities

A toolbox of small BDU tools. Each one has its guide in `references/` and its script in `scripts/`. Read the
guide for the tool you need.

| Tool | What it does | Guide |
|---|---|---|
| Video references | Study a video from a link or file: frames, transcript with timings, caption, cuts and pauses | `references/video-reference.md` |
| Compress a PDF | Make a heavy PDF (above all Canva exports) 6–8× smaller with no visible loss and the same colours | `references/compress-pdf.md` |

**Adding a tool:** one row here, one guide in `references/`, and scripts in `scripts/`. Add the triggers
to the description above, so the skill is picked up for the new job. A tool used in only one job stays in that
job’s `tools/`. A tool that grows into a discipline of its own becomes its own skill.

**These are defaults, not laws.** The designer on the job can change any rule here, case by case, when their
judgement says the piece needs it. Say which rule is being set aside and why. A rule that keeps being broken is
a sign it should change: tell ochavisual@un.org.
